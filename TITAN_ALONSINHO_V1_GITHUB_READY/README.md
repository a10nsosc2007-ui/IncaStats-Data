# TITAN ALONSINHO V1 PRO — GitHub Ready

Base consolidada: **731 equipos** (Europa 585 + América 146), 2021–2026.

## Publicar gratis
1. Descomprime `TITAN_ALONSINHO_V1_GITHUB_READY.zip`.
2. Sube su contenido a la raíz de un repositorio público en GitHub.
3. Settings → Pages → Deploy from branch → `main` / root.
4. La web carga cada CSV de equipo bajo demanda.

## Release
Sube `TITAN_ALONSINHO_V1_FULL_DATA_RELEASE.zip` como asset de una GitHub Release para conservar portal_ready global, partidos, tarjetas y auditorías.
